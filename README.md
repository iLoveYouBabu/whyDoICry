# Why do I cry? — Mobile Edition V5.1

공항의 낯선 인사, 세 해 전으로 이어지는 터널, 함께 보낸 일 년에서 시작되는 한국어 멀티엔딩 비주얼노벨입니다. 이야기 설정을 바탕으로 게임용 대사와 분기를 각색한 판입니다.

## 실행

ZIP을 전부 압축 해제하고 **index.html**을 브라우저에서 여세요. 외부 패키지 설치, 인터넷 연결, 빌드 과정 없이 PC에서 실행할 수 있습니다. 브라우저의 파일 보안 정책에 따라 저장 동작이 다를 수 있으므로 진행 백업 기능을 함께 제공합니다.

휴대폰에서는 파일 앱의 HTML 미리보기 대신, 다음 방법으로 브라우저에서 실행하세요.

1. PC와 휴대폰을 같은 Wi-Fi에 연결합니다.
2. Python 3가 설치된 PC에서 `start.bat`을 실행하거나 `python3 serve.py`를 실행합니다.
3. 서버 창에 표시된 주소를 휴대폰 브라우저에 입력합니다.
4. 게임을 마친 뒤 서버 창에서 `Ctrl+C`를 누릅니다.

로컬 네트워크 접속이 안 되면 PC 방화벽에서 해당 서버의 개인 네트워크 접근 허용 여부와 두 기기의 Wi-Fi를 확인하세요. 모바일 핫스팟·게스트 Wi-Fi처럼 기기 사이의 접속을 막는 네트워크에서는 연결되지 않을 수 있습니다. 서버를 실행하는 동안 이 게임 폴더의 파일을 같은 네트워크에서 읽을 수 있습니다.

서버는 게임 폴더만 제공하며 계정·분석 도구·외부 API를 사용하지 않습니다. 압축본에는 배포 주소나 저장소 계정 정보가 포함되지 않습니다.

## 이번 판

- 2023~2024년의 진실·귀환 준비·장소 약속·작별 방식으로 엔딩이 결정됩니다. B의 결말은 봄의 관계·돌아온 뒤의 마음을 확인하기로 한 약속·마주한 작별로 결정됩니다. 두 사람의 시점과 마지막 귀환 이후에는 선택지가 없습니다.
- 산장 열쇠를 빌려준 친구 B의 이야기가 본편에 합류합니다. 2023년 가을에 명시적으로 루트를 고르며, B의 기억에서는 2025~2026년에 친구로 지냈던 시간을 읽습니다.
- 메인 엔딩 8개와 짧은 세계 붕괴 엔딩 1개. 겨울과 생일에 미뤄 둔 대답을 보완할 기회가 있습니다.
- 기존 장면 17장에 B 전용 세로 이미지 12장을 더해 총 29장을 사용합니다. 첫 만남·커피·작별·친구로 지낸 날들·재회·배드엔딩을 구분하며, B의 겨울·커피·작별·재회 표정을 서로 다르게 구성했습니다.
- 첫 장면은 미리 불러오고, 다음 대사·선택지의 장면은 브라우저가 한가할 때 예열합니다. 큰 배경 WebP만 용량을 줄였으며, A·B 인물 이미지의 원본 얼굴 품질은 다시 압축하지 않았습니다.
- 마침표 뒤 줄바꿈, 날짜·말줄임표 보존, 긴 문장의 화면별 나누기를 적용했습니다.
- 대사와 선택지를 화면 아래 같은 영역에 배치. 글자 크기에 따른 문장 나누기, 화면 탭 진행, 드래그 오작동 방지, 선택지 표시 직후 연속 터치 방지.
- 자동 읽기, 이미 읽은 문장 건너뛰기, 이전 문장, 전체 대화 기록, 기억·약속 보관함.
- 자동 저장, 수동 저장 3칸, 직전 선택 재시도, 방문한 분기 다시 읽기, JSON 백업 내보내기·불러오기.

## 조작

| 입력 | 동작 |
| --- | --- |
| 화면 탭 / 계속 / Space / → | 글자가 나오고 있으면 전체 표시, 다 나온 뒤에는 다음 페이지 |
| 이전 / ← | 이전 페이지 또는 이전 대사·선택으로 |
| 자동 / A | 자동 읽기 켜기·끄기. 선택에서는 기다림 |
| 읽은 글 / S | 읽은 내용만 빠르게 진행. 새로운 대사 또는 선택에서 정지 |
| 메뉴 / Esc | 읽기 메뉴 |
| 메뉴 → 장면만 보기 | 대화창을 숨기고 장면 전체 보기 |

긴 문장은 글자 크기와 화면 폭에 맞춰 여러 페이지로 나눕니다. 글자를 아주 크게 보거나 브라우저를 확대하면 대화 영역을 스크롤할 수 있습니다. 화면 회전 시 현재 문장을 유지하며, 겹치는 일부 문장이 다시 보일 수 있습니다.

## 저장과 개인정보

이름, 닉네임, 연락처, 계정 정보를 입력받지 않습니다. 사용자 이름이나 개인 크레딧, 원작 게시물·프로필 주소, 저장소·배포 주소는 압축본에 들어 있지 않습니다. 사진 원본은 넣지 않았으며 게임용 WebP 이미지의 EXIF·XMP 등 메타데이터를 제거했습니다.

브라우저에는 게임 진행만 저장합니다. 원격 전송, 광고, 통계, 추적 SDK, 외부 폰트 요청은 없습니다. 선율도 브라우저 안에서 직접 합성합니다.

저장 키는 `wdic-mobile-v5`입니다. 스토리 분기와 엔딩이 바뀌어 V1·V2·V3·V4 저장을 자동 변환하지 않으며, 기존 저장 키를 삭제하지도 않습니다. 자동 저장은 현재 진행으로 갱신되고 수동 저장칸과 엔딩 기록은 별도로 남습니다. ‘처음부터’는 자동 저장을 덮어쓰므로 필요하면 수동 저장하거나 백업하세요.

백업 JSON은 게임의 저장 메뉴에서만 가져오면 됩니다. 기기별 저장을 자동 병합하지 않고 백업 내용으로 교체합니다. 교체 전 현재 진행을 내려받을 수 있습니다. 브라우저가 로컬 저장을 제한하거나 저장 공간이 부족하면 안내가 표시되며, 파일 백업은 계속 사용할 수 있습니다.

## 소스 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 게임 실행 진입점 |
| `src/story.js` | 전체 대사, 선택지, 엔딩, 기록 |
| `src/engine.js` | 진행·되돌리기·재시도·저장 검증·문장 나누기 |
| `src/app.js` | 화면, 입력, 메뉴, 로컬 저장과 백업 |
| `src/style.css` | 모바일·PC 화면과 읽기 설정 |
| `src/audio.js` | Web Audio로 만든 오리지널 합성 선율 |
| `assets/` | 게임용 이미지와 아이콘 |
| `docs/storyboard.html` | 이미지와 모든 분기를 함께 보는 스토리보드. 스포일러 포함 |
| `docs/story-rules.md` | 시간 규칙, 엔딩 조건, 선택의 영향. 스포일러 포함 |
| `docs/story.md` | 선택 경로별로 이어 읽는 전체 이야기 원고 |
| `docs/art-prompts.json` | 이번에 생성한 장면의 제작 프롬프트 |
| `tools/verify.mjs` | 외부 패키지 없이 실행하는 논리 검증 스크립트 |
| `serve.py`, `start.bat` | 같은 Wi-Fi의 모바일 기기에서 실행하는 로컬 서버 |

게임 파일은 일반 JavaScript로 작성되어 있어 `src/story.js`를 수정하고 새로고침하면 바로 반영됩니다. 스토리보드도 같은 이야기 파일을 읽습니다. 기존 진행과 호환되지 않는 변경을 할 때는 `STORY_VERSION`과 저장 형식을 함께 올리세요.

## 검증

Node.js가 있다면 프로젝트 폴더에서 `node tools/verify.mjs`를 실행하세요. 전체 99개 장면·52개 선택 연결·9개 엔딩을 29개 경로로 확인합니다. A의 네 조건, B의 세 갈래 결말, 고백 번복과 약속 보완 경로도 검사합니다. 저장 복원, 재시도, 잘못된 백업 거부, 읽음 구분, 줄바꿈과 페이지별 문장 보존, 이미지 참조도 검사합니다.

실제 모바일 기기나 브라우저를 조작한 화면 검증은 수행하지 않았습니다. 구체적인 검사 결과는 `docs/verification.json`에 있습니다.

## 읽기 화면 수정

- 진행 숫자는 현재 장면에서 실제 넘겨 읽는 전체 페이지를 기준으로 한 번만 표시합니다.
- 본문, 엔딩 문장, 기록은 읽기 설정을 따르고, 선택지는 모바일 16px로 고정해 선택지끼리 크기가 흔들리지 않도록 했습니다.
- 모바일 브라우저의 자동 글자 확대를 고정하고, 사용자의 확대·축소는 유지합니다.
- A의 첫 만남·겨울·기타·생일·공항 장면은 서로 다른 원본 표정을 기준으로 수정했습니다.
- 긴 대사와 인용문은 말 중간에서 끊지 않고, 필요한 경우 대화창 안에서 스크롤해 끝까지 읽습니다.
