Why do I cry? — Mobile Edition

1. ZIP 파일을 먼저 전부 압축 해제하세요.
2. 폴더 안의 index.html을 Chrome, Edge, Safari 또는 Firefox에서 여세요.
   PC에서는 별도 설치나 빌드 없이 바로 실행할 수 있습니다.
3. 소리는 게임 안의 소리 버튼을 눌러 켜세요.

모바일로 실행하려면:
- 휴대폰 파일 미리보기 앱은 웹 게임 실행을 지원하지 않을 수 있습니다.
- 같은 Wi-Fi의 PC에서 아래 서버를 실행한 후 휴대폰 브라우저로 접속하세요.
  Windows: start.bat 실행 (Python 3 필요)
  macOS / Linux: 터미널에서 python3 serve.py
- 서버 창에 표시되는 주소를 휴대폰 브라우저에 입력하세요.
- 실행 중인 PC와 서버 창을 켜 두세요. 종료는 Ctrl+C입니다.

백업:
- 게임의 저장 메뉴 → 전체 진행 내려받기
- 다른 기기에서 저장 메뉴 → 백업 파일 불러오기
- 브라우저 기록을 지우거나 폴더 위치를 바꾸기 전에 백업하세요.
- 이전 판의 저장 데이터와 분리되며, 이전 저장 파일을 자동 변환하지 않습니다.

소스: src/ 안의 파일을 수정한 뒤 index.html을 새로고침하세요.
스토리보드: docs/storyboard.html (전체 엔딩 스포일러 포함)
실행 안내와 파일 구성: README.md

이 압축본은 사용자의 이름, 연락처, 계정 정보, 원문 게시물 주소,
저장소 주소를 포함하지 않습니다. 장면 이미지의 메타데이터도 제거했습니다.
원본 업로드 사진은 포함하지 않았습니다.
