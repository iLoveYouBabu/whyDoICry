본편의 두 갈래

친구에게 산장 열쇠를 빌림 → 공항의 눈물 → 터널을 지나 2023년 → 산장의 그녀와 첫 만남 → 미래의 친구와 첫 만남.
2023년 가을에 누구와 더 많은 시간을 보낼지 직접 선택합니다.
첫 만남 전에 버스로 떠나면 세계 붕괴로 끝납니다.

산장의 그녀친구의 이야기
겨울의 진실 → 봄의 노래 → 여름의 장소 약속 → 생일의 준비 → 폭풍우의 작별.
진실·준비·장소·마주한 작별이 모두 있어야 재회합니다.		겨울의 고백 → 봄에 정하는 관계 → 여름의 미래와 약속 → 가을의 보완 → 폭풍우의 작별.
봄의 고백·돌아온 뒤의 약속·마주한 작별이 모두 있어야 연인으로 재회합니다.
처음부터 친구를 택하거나, 사랑을 택했어도 기다림 속 마음이 달라지면 각기 다른 친구 결말로 이어집니다.
그녀가 보낸 두 해 → 공항에서 시작을 지킴 → 과거 선택에 따른 결말.2025년에 나를 모르는 그와 친구가 됨 → 산장을 사서 빌려줌 → 공항의 그녀는 다른 사랑을 보내고 떠남 → 친구·늦은 마음·재회 중 하나로 마주 앉음.

두 사람의 기억과 2026년 귀환 뒤에는 선택이 없습니다.
잔류·동행은 각 루트의 세계 붕괴 배드엔딩이며, B가 사랑을 택한 뒤 메시지만 남기면 ‘늦게 도착한 마음’으로 이어집니다.
B가 처음부터 친구를 택한 경우에는 마주한 작별 여부와 관계없이 친구 결말을 맞고, 세계는 유지됩니다.
